# ABC・0カウント分析 Web アプリ（試作品）

ブラウザ内で CSV を集計する静的 Web アプリです。サーバーへの CSV 送信処理はありません。

## 使い方
1. GitHub Pages の Settings → Pages を開き、Build and deployment → Deploy from a branch を選択。
2. Branch に `master`、Folder に `/docs` を設定して保存します。
3. GitHub Pages の画面に表示される公開 URL を開きます（通常は https://juntainoue.github.io/test/ ）。
4. 内蔵の架空データで集計を確認した後、CSVをアップロードします。

## CSV の仕様
UTF-8 の CSV、1行目ヘッダー、列順は `店舗,JAN,商品名,売上,在庫`。
- 店舗：任意の文字列
- JAN：文字列（先頭0を保持）
- 商品名：同一 JAN で同じ名称
- 売上：0以上の数値
- 在庫：0以上の数値。0を0カウントと判定
- 同じ店舗と JAN の組み合わせは1行のみ

## ABC 判定
全店舗で JAN ごとに売上を合計し、売上の大きい順に並べます。
累計売上構成比について、各商品の**直前**が75%未満なら A、95%未満なら B、それ以外を C にします。
閾値をまたぐ商品は上の区分に入れます。売上合計が0の場合は全件 C。
運用前に正式なABC基準との突合が必要です。

## 情報の取り扱い
このリポジトリは公開設定です。実際の会社の売上CSVや内部資料をコミットしないでください。
ブラウザで読み込んだCSVを送信する機能はありませんが、公開ページでの業務データ利用にあたっては会社の情報管理規程を確認してください。
