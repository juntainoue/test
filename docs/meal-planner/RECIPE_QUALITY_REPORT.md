# レシピ品質改善の報告

実施日: 2026-11-11（日本時間）

## 着手時の問題

- 60品のうち約45品の手順が、料理に関係なく使い回された汎用文でした（例：焼き餃子が「下処理して食べやすく切る→火の通りにくい食材から炒める」で、包む・蒸し焼きの工程がない。米を炒めて作るリゾットが「米を炊飯し」になっている）。
- 手順に必要な調味料・油が材料にありませんでした（例：かつおのたたきの「香味だれ」、さばの味噌煮の砂糖・酒、焼き油全般）。
- 水量・火加減・加熱時間がほぼ記載されていませんでした。
- 肉・魚・卵料理の多くで、火が通ったことの確かめ方が書かれていませんでした。

## 実施内容

- 全60品の手順を料理ごとに書き直しました（3〜5工程）。切り方、火加減、加熱時間、水量、火の通りの確認方法を具体的に記載しています。
- 手順で使う油・塩・砂糖・酒などを材料に追加しました。**既存の材料名・数量・単位は変更していません**（買い物チェックの保存データと互換）。追加した材料は買い物リストにも表示されます。
- 水量は `水{{150|ml}}` の形でデータに記載し、選んだ人数に合わせて換算表示します（例：肉じゃが4人分で「水600ml」）。
- 食品安全に関する記載を追加しました。
  - ひき肉料理：中心部75℃で1分以上の加熱を目安とし、肉汁と色で確認
  - 鶏肉料理：厚い部分を切って中まで白いこと・透明な肉汁を確認
  - 親子丼・カルボナーラなど半熟卵：作りたてを食べる、配慮が必要な方には十分に加熱
  - かつおのたたき：生食用を使い当日中に調理、生魚に注意が必要な方への注意
  - カシューナッツ：ナッツ類のアレルギーへの注意
- 炊いたごはんを使う料理は「炊飯時間は調理時間に含まない」と明記しました。調理時間（`time`）の値は変更していません。
- 卵料理・生魚など5品の保存目安を、料理に合わせて修正しました。
- 各レシピに確認状態 `recipeCheck`（`desk-reviewed`、`cookTested: false`）を追加し、詳細画面に「机上で確認済み（試作による検証は未実施）」と表示します。

## 自動テスト（追加分）

`tests/recipes.test.js`

- 材料一覧の全食材が手順に登場すること（「豚ひき肉→ひき肉」などの略称は対応表で判定）
- 同じ材料の重複がないこと、3工程以上・加熱時間の記載があること、旧汎用文が残っていないこと
- 肉・魚・卵を使う料理に火の通りの確認方法があること（生食・半熟は注意書きを確認）
- 手順の水量が人数分に換算されること、不正な分量表記・確認状態を検出できること
- 60品すべてが「机上確認のみ・試作未実施」として記録されていること

旧データに対してこのテストを実行すると6件中4件が失敗し、改善前の問題を検出できることを確認しました。

## 未解決・注意事項

- **試作は未実施です。** 味の濃さ、仕上がり、加熱時間が実際に適切かは、試作で確認する必要があります。確認後に `cookTested: true` へ変更してください。
- 栄養値（kcal・たんぱく質）は従来どおり未検証の暫定概算です。今回追加した油・調味料は栄養値に反映していません。
- 加熱時間は1〜2人分の目安で、人数が多い場合は自動で変わりません。画面に注意書きを表示しています。
- めんつゆは3倍濃縮を前提に水量を記載しています（他の濃縮倍率は表示に合わせて調整する旨を記載）。
- 電子レンジの時間は600Wを前提としています。
