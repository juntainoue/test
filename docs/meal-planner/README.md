# ごはん計画 — 献立・買い物Webアプリ

**URL:** https://juntainoue.github.io/test/meal-planner/

静的HTML / CSS / JavaScriptだけで動作するプロトタイプです。APIキー・外部サービス・サーバーは不要です。

## 機能
- 3日または7日分の夕食の提案（内蔵の60レシピから選択）
- 1〜4人分の材料数量計算
- 和食 / 中華 / 洋食の選択、辛くない料理の指定、辛口優先
- 日ごとの別メニュー再提案
- 材料の合算と買い物チェック、クリップボードへのコピー
- レシピ名・材料名検索、調理手順と保存上の注意
- ブラウザのlocalStorageによる端末内保存

## 制約
- 生成AI連携ではありません。現段階は登録済みレシピに基づく自動献立提案です。
- レシピ・分量は一般的な目安で、医療的栄養管理・アレルギー対応はありません。
- ブラウザ保存データは端末・ブラウザごとに別です。消去すると失われます。
- GitHub Pagesのサイト自体は公開されます。献立データは送信しませんが、共用端末利用には注意してください。
- コードの構文確認は実施。実ブラウザ操作と端末横断でのテストは未実施です。

## 60レシピへの拡張について
- 和食・洋食・中華を中心に48品追加しました。
- 追加品は材料・簡易調理手順・保存目安を含みます。工程や栄養値は未監修の試作品であり、実際の調理・栄養管理の際は確認が必要です。
- 料理画像は料理ごとの簡易イラストです。料理の実物写真ではありません。
- 栄養値は仮の目安で食品成分表に基づく正確な計算ではありません。商用利用前の監修が必須です。
- 条件に合う料理が7種類未満の場合、献立に同じ料理が重複する場合があります。
