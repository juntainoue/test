# デザイン・使い勝手の改善

2026-11-11

## 変更

- 白と深緑、柔らかい背景色に統一し、料理写真を生かしたトップ画面に刷新しました。
- 献立作成の条件をPCは3列、スマホは2列で整理し、提案ボタンを見つけやすくしました。
- タブをスクロール中も上部に固定し、画面切り替え時は操作する画面へスクロールします。
- 詳しいアプリ説明は開閉式にし、栄養値の暫定表示は常時維持しました。
- 料理名・食材の複数語検索、ジャンル・調理時間の絞り込み、時間順・たんぱく質順（暫定）の並べ替え、結果件数と条件クリアを追加しました。
- お気に入りの保存・解除と、お気に入りだけの表示を追加しました。ブラウザ保存ができない場合は画面に案内します。
- タッチしやすいボタン、フォーカス表示、読み上げ用のボタン名・保存状態、動きを減らす設定に対応しました。

## 検証

`npm test` の7テストが成功。既存の栄養条件192通りに加え、複数語・ジャンル・調理時間・お気に入りの組み合わせ、並べ替え、元データが変更されないことを検証しました。

Chromiumのブラウザテストは最終実行で136項目のチェックが成功しました（材料品目数により項目数は変動します）。既存の献立・買い物機能と全20画像に加え、お気に入りの再読み込み後の復元・解除、空のお気に入り、検索条件の組み合わせ・クリア、結果件数、献立条件への非干渉を検証しました。PC1440pxとスマホ等320/375/390/768pxで横にはみ出さないことを確認しました。PC・スマホ幅のスクリーンショットも目視確認しました。

変更は `docs/meal-planner/` のみ。レシピ60品・画像20品・既存の献立保存データは維持しています。栄養計算の精度改善、残り40品の画像、実スマホ検証は引き続き次の課題です。公開反映はPRのマージ後です。
