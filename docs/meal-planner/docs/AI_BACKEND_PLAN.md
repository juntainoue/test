## なぜ追加の構成が必要か

現在の公開サイト（GitHub Pages）は、HTML・JavaScriptなどのファイルをそのまま配るだけの仕組みです。AIのAPIを使うには秘密の「APIキー」が必要ですが、ブラウザで動くプログラムやGitHubに置いたキーは、誰でも見て使えてしまいます（不正利用されると費用が請求されます）。

そのため、**キーを安全に保管し、ブラウザの代わりにAIへ問い合わせる小さなサーバー（バックエンド）**が別に必要です。

```
ブラウザ（GitHub Pages）
   │  条件・選んだ料理・自宅の食材名だけを送る（キーは持たない）
   ▼
バックエンド（新規）── APIキーを秘密の設定として保管
   │  ・利用回数の上限、利用者の確認
   │  ・AIに構造化した形式（JSON）で回答させる
   ▼
AI API（例：Anthropic の Claude API）
```

アプリ側には、バックエンドの応答を検証して表示する部分を実装済みです（`js/ai.js`）。バックエンドの住所を `data/ai-config.json` に書くだけで接続できる作りにしてあり、今は空欄（未接続）です。

## 構成案

| 項目 | 案 | 補足 |
| --- | --- | --- |
| バックエンド | Cloudflare Workers などのサーバーレス関数 | 小規模なら無料枠の範囲で動く見込み。無料枠の条件は契約前に最新の内容を確認します |
| APIキーの保管 | バックエンドの「シークレット」設定 | ブラウザ・localStorage・GitHubには置かない |
| AIの呼び出し | Anthropic 公式SDKで構造化出力（JSON）を指定 | アプリ側でさらに形式・数量・安全面を検証 |
| 不正利用対策 | ①利用者の限定（例：Cloudflare Access のログイン）②1日あたりの回数上限 ③AI API側の月額上限 | 初期は依頼者だけが使える設定を推奨 |
| 費用の上限 | AI APIの管理画面で月額の利用上限を設定 | 上限額は決めていただく必要があります |

## 費用の目安（AI API）

1回の提案（新しい料理を3品程度）を、入力 約2,500トークン・出力 約4,000トークン（考える過程を含む）と仮定した試算です。実際の量は指示文や出力の長さで変わります。円換算は1ドル＝150円と仮定しています。

| モデル | 料金（100万トークンあたり 入力/出力） | 1回あたり | 1日3回×30日 |
| --- | --- | --- | --- |
| Claude Opus 5.5（最も高性能・推奨の既定） | $4 / $20 | 約$0.09（約14円） | 約$8（約1,200円） |
| Claude Sonnet 5.5 | $2 / $10 | 約$0.045（約7円） | 約$4（約600円） |
| Claude Haiku 5.5 | $0.10 / $0.50 | 約$0.002（約0.3円） | 約$0.2（約30円） |

- 料金は2026年11月時点のAnthropic公式の単価です。契約前に最新の料金を確認します。
- レシピの品質と安全面を重視し、既定は Claude Opus 5.5 を提案します。費用を抑えたい場合のモデル選択は依頼者の判断です。品質の比較は、実際に数回試してから判断するのが確実です。
- 公開して多くの人が使う場合は、利用回数に比例して費用が増えます。公開前に利用制限と上限額が必要です。
